Flat All Dimensions datapack

A datapack that unlocks the minecraft:flat_all_dimensions world type in the world creation menu

Features

Adds the minecraft:flat_all_dimensions world type to the list of available world presets

Setup

  1. Adding to the world: Open the world creation menu and click the "More" tab. Click "Data Packs". Drag the datapack file (usually a .zip file) onto the window and confirm that you want to add it. Enable the datapack by clicking on the ▶ right-facing triangle that appears on the datapack's icon when you hover over it. Click "Done".
  2. Click the "World" tab.
  3. Click the "World Type" button until it says "World Type: Flat All Dimensions".
  4. Configure any other settings you want to set and create the world.
    5. IMPORTANT: This datapack cannot be added to an existing world. It must be enabled during world creation.
